## 一、项目背景

### 1.1 项目简介
EnterpriseAdmin 是一套面向中大型企业的后台管理系统，采用 Spring Boot + Vue + Element UI + MySQL + Redis + JWT 前后端分离架构，提供用户管理、角色权限（RBAC）、部门岗位、字典管理、系统监控、定时任务、代码生成、文件存储等 20+ 功能模块。系统将作为企业内部运营管理平台投入使用，对权限安全、数据一致性、接口稳定性有较高要求。

### 1.2 测试目的
- 验证系统各功能模块是否符合需求规格说明书与产品原型。
- 验证 RESTful 接口在正向/异常场景下的正确性与健壮性。
- 验证数据库在增删改查操作后的数据一致性与关联完整性。
- 识别系统安全风险（SQL 注入、XSS、文件上传绕过、越权访问等），保障系统上线安全基线。
- 通过完整缺陷管理与回归验证，给出可量化的准出评估，支撑上线决策。

### 1.3 测试依据
- 《EnterpriseAdmin 需求规格说明书 V1.2》
- 《EnterpriseAdmin 接口文档（Knife4j）》
- 《RBAC 权限模型设计文档》
- 行业安全测试规范（OWASP Top 10）

## 二、测试范围

### 2.1 功能测试范围

| 模块 | 测试内容 | 是否纳入 |
| --- | --- | --- |
| 登录认证 | 账号密码登录、验证码、Token 刷新、退出 | 是 |
| 用户管理 | 增删改查、启用/禁用、密码重置、批量导入 | 是 |
| 角色管理 | 角色 CRUD、菜单分配、接口权限、三级联动 | 是 |
| 部门岗位 | 部门树 CRUD、岗位管理、人员分配 | 是 |
| 字典管理 | 字典类型 CRUD、字典数据 CRUD | 是 |
| 系统监控 | 在线用户、服务器监控、Druid 监控 | 是 |
| 定时任务 | 任务 CRUD、启停、执行日志、Cron 表达式 | 是 |
| 代码生成 | 表导入、模板配置、预览下载 | 是 |
| 文件存储 | 上传、下载、类型校验、大小限制 | 是 |
| 通知公告 | 公告发布与查询 | 否（二期） |
| 个人中心 | 信息修改、密码修改 | 是（轻量） |

### 2.2 接口测试范围
覆盖核心 API：登录接口、用户 CRUD、角色权限分配、定时任务管理、文件上传。包含 Token 过期、权限越权、参数注入等异常场景。

### 2.3 数据库测试范围
覆盖核心表的数据一致性与关联完整性：sys_user、sys_role、sys_role_menu、sys_dept、sys_post、sys_dict_type、sys_dict_data、sys_job、sys_job_log、sys_file、sys_logininfor、sys_oper_log。

### 2.4 安全测试范围
覆盖：文件上传类型校验、SQL 注入防护、XSS 防御、CSRF 防护、接口限流、越权访问（水平越权/垂直越权）。

### 2.5 不测试范围
- 第三方组件源码内部逻辑。
- 前端框架（Vue/Element）自身缺陷。
- 性能压力测试（单列计划，本次不纳入）。
- 兼容性测试仅覆盖 Chrome/Edge 最新版。

## 六、风险评估

| 风险项 | 影响 | 等级 | 应对措施 |
| --- | --- | --- | --- |
| 接口文档与实现不一致 | 用例设计偏差 | 中 | 以实际接口为准，及时与开发对齐 |
| 测试环境资源不足 | 进度延迟 | 中 | 提前申请，预留备用环境 |

| 定时任务测试周期长 | 进度风险 | 低 | 手动触发执行，缩短验证周期 |
