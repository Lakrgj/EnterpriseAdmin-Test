## 一、测试概况

本次测试针对 EnterpriseAdmin 企业级后台管理系统，覆盖功能测试、接口测试、数据库测试、安全测试四个维度，验证系统 8 大核心模块的可用性、稳定性与安全性。测试遵循「计划 → 设计 → 执行 → 缺陷 → 报告」完整流程，使用 Postman/Newman 执行接口回归，SQL 脚本验证数据一致性，手工 + 工具结合完成安全渗透。

被测系统采用 Spring Boot + Vue + Element UI + MySQL + Redis + JWT 前后端分离架构，提供 20+ 功能模块。本次纳入测试的 8 大核心模块为：用户管理、角色权限 RBAC、部门岗位、字典管理、系统监控、定时任务、代码生成、文件存储。

## 四、接口测试结论

- 42 条接口用例覆盖登录、用户 CRUD、角色权限、定时任务、文件上传，含 20 条异常场景用例（Token 过期、越权、参数注入）。
- 鉴权链路验证通过：登录获取 Token → 自动注入 → 过期/伪造 Token 返回 401。
- 越权场景验证通过（修复后）：水平越权修改他人数据返回 403，垂直越权访问高权限接口返回 403。
- Newman 回归集合执行通过，可纳入 CI 流水线。

## 九、测试建议

1. **安全**：上线前复核生产环境 HTTPS、限流阈值、文件存储目录无执行权限、Cookie 安全属性。
2. **接口回归**：将 Postman/Newman 集合接入 CI/CD，每次构建自动执行接口回归。
3. **数据库**：定期通过 Druid 监控分析慢查询，优化高频 SQL 索引。
4. **后续测试**：补充性能压力测试、通知公告模块功能测试、移动端兼容性测试。
5. **监控**：上线后开启操作日志与登录日志审计，关注异常登录与越权尝试。
