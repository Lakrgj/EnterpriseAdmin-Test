## 一、项目概述

本项目为「企业级后台管理系统（EnterpriseAdmin）」的完整测试工程，覆盖系统从测试计划制定、用例设计、接口测试执行、数据库验证、安全测试到缺陷管理与测试报告输出的全流程。

### 被测系统简介

EnterpriseAdmin 是一套基于主流技术栈构建的企业级后台管理系统，采用**前后端分离**架构，提供 RBAC 权限模型、部门岗位、字典管理、系统监控、定时任务、代码生成、文件存储等 20+ 功能模块，满足中大型企业内部运营管理的典型需求。

| 维度 | 说明 |
| --- | --- |
| 后端技术 | Spring Boot 2.7 + Spring Security + JWT + MyBatis-Plus + Druid 连接池 |
| 前端技术 | Vue 3 + Element Plus + Axios + Pinia + Vue Router |
| 数据存储 | MySQL 8.0（业务数据） + Redis 6（缓存/会话/限流） |
| 鉴权方案 | JWT Token（Access Token + Refresh Token），基于 RBAC 的接口级权限控制 |
| 部署方式 | Docker 容器化部署，Nginx 反向代理 |

## 三、测试策略

1. **分层测试**：先接口后功能，先单模块后业务链路，保证缺陷早发现。
2. **等价类/边界值**：对输入字段（用户名、密码、文件大小、Cron 表达式）采用等价类划分与边界值分析。
3. **场景法**：针对「角色分配权限 → 用户登录 → 访问菜单」等业务链路进行场景化测试。
4. **数据库断言**：每个写操作接口执行后，通过 SQL 校验落库数据一致性。
5. **安全渗透**：使用 Postman/Burp/SQL 语句模拟注入、越权、上传绕过等攻击向量。
6. **自动化回归**：使用 Newman 执行 Postman Collection，实现接口回归自动化。
